# 🌱 畑ノート

家庭菜園の畑・畝を管理するPWAアプリです。

## 機能

- 畑のレイアウト管理（グリッドマップ）
- 縦・横の通路設定
- 野菜の作付け記録（種/苗の区別）
- 収穫予定日の自動計算
- 連作障害チェック＋避けるべき野菜の表示
- 地域別播種カレンダー（寒冷地・温暖地・暖地）
- 作付け履歴
- 長押し＆スワイプでコピペ
- 次にやる作業メモ
- 畑ごとのパスワード設定（共有管理）予定
- PWA対応（iPhoneのホーム画面に追加可能）

## セットアップ

```bash
# 依存関係をインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## Vercelへのデプロイ手順

1. [GitHub](https://github.com) にこのフォルダをリポジトリとしてアップロード
2. [Vercel](https://vercel.com) でアカウント作成
3. 「Add New Project」→ GitHubリポジトリを選択
4. そのまま「Deploy」をクリック
5. 数分でURLが発行されます

## iPhoneのホーム画面に追加する方法

1. SafariでVercelのURLを開く
2. 画面下の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. アイコン名を確認して「追加」

これでアプリのように起動できます。

## アイコン画像について

`public/` フォルダに以下のPNG画像を追加してください：

- `icon-192.png` （192×192px）
- `icon-512.png` （512×512px）
- `apple-touch-icon.png` （180×180px）

緑の背景に🌱の絵文字を配置したシンプルなデザインを推奨します。

## 技術スタック

- Vite 5
- vite-plugin-pwa（PWA対応）
